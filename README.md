# Muskan Sondhiya — AI/ML & Data Science Portfolio

Interactive React/Vite portfolio focused on AI/ML, Data Science, NLP, GenAI and deployed applications.

## Run locally

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
npm run preview
```

## Free deployment

### Vercel
1. Push this folder to a GitHub repository.
2. Import the repository into Vercel.
3. Framework: **Vite** (usually detected automatically).
4. Build command: `npm run build`.
5. Output directory: `dist`.
6. Deploy.

### Netlify
1. Push to GitHub.
2. Add the repository in Netlify.
3. Build command: `npm run build`.
4. Publish directory: `dist`.
5. Deploy.

No API keys are required for the portfolio itself.
